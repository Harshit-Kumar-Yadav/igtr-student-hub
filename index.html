ATTENDANCE MANAGEMENT

Daily Attendance,
Managed Securely.

IGTR Student Hub attendance system is designed for authorized batch incharges. Teachers can mark the daily morning attendance for their assigned batch, while students can only view their own attendance from their profile.

🔐 Teacher Controlled Only authorized teachers can mark attendance.
📅 Daily Attendance One attendance record is maintained for each batch per day.
👨‍🎓 Student Read Only Students can view only their own attendance.
💾 Secure Storage Attendance is stored on the server for future records.
